# 工作集 Workset

Windows 桌面效率工具。把一项工作需要的表格、文档、文件夹、在线链接和脚本集中到一个工作集页签，随时打开。完整模式管理内容，精简模式只负责启动；最小化后收起为可拖动的悬浮气泡。

## 启动

**本机已有便携版时**，双击本目录 `start.bat`，或直接打开 `dist/Workset-win32-x64/Workset.exe`。便携版不需要安装 Node.js；分发时需要保留整个 `Workset-win32-x64` 文件夹，不能只复制 exe。

**从源码启动**，使用 Windows 10/11、Node.js 22.12 或更新版本，在本目录执行：

```powershell
cd D:\project\LDTools\workset
npm ci
npm start
```

首次启动需要下载 Electron 桌面运行时。日常运行无需联网、账号、数据库或本地 Web 服务；打开在线文档时仍需网络。

## 使用

1. 在完整模式点左侧 **新建工作集**，例如“装备配置”。点标题旁的编辑按钮修改名称和说明。**删除工作集**直接显示在标题旁，左侧每个页签旁也有删除图标；确认后删除整个工作集及快捷方式，原文件保留。允许删除最后一个工作集，空列表中仍可重新新建。
2. 点 **添加快捷方式 → 文档 / 脚本**，一次选择需要的四个表格；也可以拖入文件、选择文件夹，或手动添加绝对路径及 HTTP(S) 网址。
3. 点文件卡片或 **打开**，通过 Windows 默认应用打开；例如 Excel / WPS 打开表格。**一键打开**打开当前工作集的全部文档、网址和文件夹，不受搜索筛选影响。
4. 脚本显示 **运行**，点击后确认启动。整组打开会跳过脚本。`.py` 使用 `py -3`，`.ps1` 使用 `powershell.exe -NoProfile -File`，`.js/.cjs/.mjs` 使用 `node.exe`；这些脚本在所在目录启动，需对应解释器可用。`.bat/.cmd/.exe` 交给 Windows 默认方式打开。启动成功不代表脚本执行完成；本版不收集运行日志、不提供参数或停止进程功能。
5. 卡片底部可定位原文件、复制路径、编辑名称 / 路径 / 备注和移除快捷方式。文件已移动或关联应用缺失时会提示；批量打开会列出失败项。
6. 在完整模式点顶部 **窗口置顶**，窗口会一直显示在普通窗口之上，切换软件、调整窗口和从气泡展开时继续保持。此设置在退出后保留。`Ctrl+K` 聚焦完整模式中的搜索。若系统拒绝恢复置顶，界面会提示错误并同步实际状态，可回到完整模式重新点击置顶按钮启用。
7. 左下角 **导出 / 导入**用于 JSON 备份。导入会先校验，再确认替换全部工作集，并在数据目录自动备份原配置。只保存快捷方式，不复制或删除原文件。

## 精简模式与悬浮气泡

- 顶部 **精简**切换到启动面板。左侧只显示工作集页签，右侧只显示文件名称、打开入口和 **一键打开**。搜索、添加、编辑、删除、路径、备注和备份等管理操作仅在完整模式提供；精简模式也不接受拖入新增。
- 页签采用传统标签页样式，连同文字整体旋转 **90°** 放在左侧，选中页签与内容区连成一体。每列根据完整名称和窗口高度安排，向外最多堆叠 **3 列**，超出后翻页。名称不缩略，极长名称在页签内换行。进入精简模式或从气泡展开时，自动定位当前页签；上下方向键切换页签，Home / End 跳到首尾。
- 精简模式默认约 `560 × 430`，可拖动标题栏或调整窗口尺寸。顶部 **完整模式**回到管理界面，并恢复原完整窗口尺寸。
- 点击任一模式右上角的收起按钮，或通过系统最小化窗口，主窗口会隐藏为 **悬浮气泡**。气泡保持置顶，可以拖动到屏幕内其他位置；拖动不会误触展开。
- **点击气泡**展开精简模式，保留当前页签；右键气泡可选择“展开精简模式”“打开完整模式”或“退出工作集”。打开第二个程序实例也能唤回收起的窗口。
- 此版本采用悬浮气泡方案，不启用自动贴边隐藏或鼠标悬停展开。窗口管理和气泡仅改变显示方式，不修改工作集内容。

配置保存在 Electron 用户数据目录中的 `settings.json`，通常为 `%APPDATA%/ldtools-workset/settings.json`；点左下角信息图标可查看本机准确路径。退出、更新源码或移动便携版目录不会清除配置。若配置损坏，程序会报告原文件位置并停止启动，避免默默覆盖数据。

## 验证

从 `workset` 目录运行：

```powershell
npm test
npm run test:desktop
npm run test:pin
npm run test:compact
```

单元测试覆盖保存与重载、导入校验、损坏配置保护、类型识别、批量打开跳过脚本、取消执行和启动错误。桌面测试使用独立的临时数据目录，验证真实 Electron 窗口中的增删改、搜索、批量选择、窗口置顶、精简模式、重启持久化、导入导出和脚本启动。测试文件及截图位于 `artifacts/`，不写入日常配置。桌面测试需要可用的 Windows 桌面会话；本版针对 Windows 实现。

`test:pin` 创建重叠的普通辅助窗口，反复切换焦点，直接检查 `WS_EX_TOPMOST` 和两个窗口的实际叠放顺序；同时覆盖精简模式、尺寸调整、最大化、最小化恢复、取消置顶，以及系统拒绝置顶时的界面错误处理。设置 `WORKSET_EXE` 为便携版 exe 的绝对路径，可对打包版运行上述桌面测试。

`test:compact` 验证完整模式的直接删除入口、删除最后一个工作集后的重启和新建、原文件保留、精简模式中只保留启动操作、页签旋转 90°、最多三列及分页、完整名称、选中页签与内容区接通、键盘切换、单独与批量打开，以及气泡置顶、拖动、点击展开、原生最小化和右键返回完整模式。所有测试均使用独立配置目录。

## 构建便携版

```powershell
npm run build
```

输出 `dist/Workset-win32-x64/Workset.exe`（架构跟随构建机）。构建为 Electron 官方运行时加本应用源码，无安装程序和自动更新。已有同名输出目录时构建会停止，请先关闭旧程序并将旧输出移走。生产版本尚未进行代码签名。

桌面接口依据 [Electron BrowserWindow 文档](https://www.electronjs.org/docs/latest/api/browser-window)、[shell 文档](https://www.electronjs.org/docs/latest/api/shell)及[安全规范](https://www.electronjs.org/docs/latest/tutorial/security)实现：渲染进程不直接访问文件系统，通过隔离桥接调用固定接口。

Windows 置顶使用 `pop-up-menu` 层级，避免默认 `floating` 层级在重新获得焦点时因任务栏排序而丢失置顶。设置后还会复核 Windows 的 `WS_EX_TOPMOST` 标志。当 Electron 设置未生效时，使用随应用打包的 Koffi 调用 [SetWindowPos](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowpos) 修正，仅操作本应用窗口，不需要额外安装 Python、PowerShell 模块或管理员权限。恢复窗口的置顶操作会等原生恢复事件结束后执行，并捕获错误。
