Windows x64 便携版：下载 ZIP，解压整个 `Workset` 文件夹，双击 `Workset.exe` 即可运行，无需安装 Node.js。

- 按工作集整理表格、文档、文件夹、在线链接和脚本，可单独打开或一键打开整组文档。
- 窗口置顶、精简启动面板，以及可拖动的悬浮气泡。
- 传统页签连同文字旋转 90° 放在侧边，完整显示名称，最多三列堆叠，超出后翻页。
- 工作集增删改、搜索、备注、JSON 导入导出和本地自动保存。

请保留解压目录中的 DLL、resources、locales 等所有文件，不能只复制 EXE。个人配置保存在 `%APPDATA%\ldtools-workset`，更新程序不会删除配置。

`SHA256SUMS.txt` 提供 ZIP 的 SHA-256 校验值。此应用尚未进行独立代码签名。
